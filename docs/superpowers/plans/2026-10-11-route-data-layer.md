# Route Data Layer (rework of PR #12) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give every customer a route (`saCliente.co_zon`) and a visit frequency (`saCliente.frecu_vist`) through the existing `mapping:build` / `mapping:apply` flow, keep each route owned by exactly one seller, and expose route, frequency, registration date and the migration-batch flag in the DWH, so plans B (Seguimiento) and C (consolidation) can read them.

**Architecture:** Pure TypeScript modules in `lib/customer-mapping/` (frequency enum, route-zone codes, route-owner derivation and coherence check) feed the CSV builder, the plan and the apply/rollback orchestration. ERP writes go only through three new `pApi*` procs (`migrations/mssql/0018`). The DWH side is one new migration (`migrations/dwh/0040`) that drops the PR #12 mapping table/view, adds columns to `dim.Dim_Customer` via a redefined `dwh.Load_Dim_Customer`, and adds `dim.Dim_Zone` / `dim.Dim_Segment` mirrors.

**Tech Stack:** Bun (`bun test`), TypeScript, `mssql` (SQL Server, T-SQL migrations), Drizzle/`bun:sqlite` (run snapshots, unchanged schema), `xlsx` (workbook I/O).

**Spec:** `docs/superpowers/specs/2026-10-11-sales-tabs-refactor-design.md` (section "A. Data layer" and the Decisions table). Builds on `docs/superpowers/specs/2026-10-11-customer-seller-segment-mapping-design.md` and `docs/superpowers/plans/2026-10-11-customer-seller-segment-mapping.md` (implemented on the parent of this branch).

- ERP writes only through `pApi*` procs; `saCliente.tip_cli` is never written; no raw UPDATE/INSERT from TypeScript.

- Mapping CSV columns, in order: `co_cli, nombre, co_ven, grupo, ruta, frecuencia, effective_from, source_note`. `tipo_cliente` and `cliente_principal` are removed.
- Coherence: `mapping:build` assigns each route's owner (seller with most customers; tie = conflict, left as-is) to every customer on that route; `mapping:apply` and `mapping:apply --verify` refuse/flag any customer without route, without seller, or whose seller is not its route's owner.
- Local ERP/DWH is a stale copy of production (`Ncake_a`). ERP-writing tests live only in `scripts/dwh/__tests__/customer-mapping-erp.test.ts` (`bun run test:mapping-erp`, non-production only). DWH integration tests use a disposable database (`DW_NAME` set at the top of the file) and run with `--timeout 30000`. Tests build synthetic workbooks in-test; the real `~/Desktop/*.xlsx` files are never read by tests.

## Review Focus

1. **Route cell formats in the tracking workbook** (`5`, `5.0`, `" 5 "`, `"Ruta 5"`, blank, `"abc"`, `0`, `1000`): none may crash the build; blank/invalid routes become a `missing_route`/`invalid_route` conflict and a blank `ruta` that blocks `mapping:apply`. Tested in Task 2 (`parseRouteNumber`) and Task 4.
2. **Zone code width and collisions**: code must fit `char(6)`, must not collide with existing `CCS-11`-style zones, and the proc must reject malformed or lower-case codes. Tested in Task 2 and Task 5.
3. **Re-running `mapping:build` over a hand-edited CSV**: must refuse to overwrite without `--force`. Tested in Task 4.
4. **Rollback of a customer whose previous `frecu_vist` was NULL or free text** (the local ERP has NULL everywhere): `pApiActualizarRutaCliente` rejects those values, so rollback uses the separate `pApiRestaurarRutaCliente`. Tested in Tasks 5 and 7.
5. **Spurious SCD2 versions**: the first `Load_Dim_Customer` after 0040, and a re-run with the watermark reset, must not close/insert rows when nothing changed; a real drift in `VisitFrequency`/`RegisteredDate` must version. Tested in Task 8.
6. **Tied or seller-less routes**: owner stays blank, customers keep their own sellers, conflict recorded, apply blocked until a human edits the CSV. Tested in Tasks 3, 4, 6.

```ts
// ERP storage: saCliente.frecu_vist (varchar(60), free in the ERP) holds one of these values.
// The same list is enforced by pApiActualizarRutaCliente (migrations/mssql/0018) and mirrored in
// dwh.Load_Dim_Customer (migrations/dwh/0040); tests pin the three copies together.
export const VISIT_FREQUENCIES = ['SEMANAL', 'QUINCENAL', 'MENSUAL'] as const;
export type VisitFrequency = (typeof VISIT_FREQUENCIES)[number];

export const DEFAULT_VISIT_FREQUENCY: VisitFrequency = 'SEMANAL';

export const VISIT_INTERVAL_DAYS: Record<VisitFrequency, number> = { SEMANAL: 7, QUINCENAL: 15, MENSUAL: 30 };

// Accents are NOT stripped: SQL Server (Modern_Spanish_CI_AS) compares them, and the DWH loader must agree.
export function parseVisitFrequency(raw: unknown): VisitFrequency | null {
  if (typeof raw !== 'string') return null;
  const key = raw.trim().toUpperCase();
  return (VISIT_FREQUENCIES as readonly string[]).includes(key) ? (key as VisitFrequency) : null;
}

export function visitIntervalDays(f: VisitFrequency | null | undefined): number | null {
  return f ? VISIT_INTERVAL_DAYS[f] : null;
}
```

`lib/customer-mapping/route-zones.ts`:
```ts
// A route is a saZona row. The code must fit char(6) (saZona.co_zon, saCliente.co_zon,
// Dim_Customer.ZoneCode), so the spec's "CCS-003" (7 chars) is written "CCS003".
export const ROUTE_ZONE_PREFIX = 'CCS';
export const MIN_ROUTE = 1;
export const MAX_ROUTE = 999;

export function parseRouteNumber(raw: unknown): number | null {
  let n: number;
  if (typeof raw === 'number') n = raw;
  else if (typeof raw === 'string') {
    const m = /^\s*(?:ruta\s*)?(\d{1,3})\s*$/i.exec(raw);
    if (!m) return null;
    n = Number(m[1]);
  } else return null;
  return Number.isInteger(n) && n >= MIN_ROUTE && n <= MAX_ROUTE ? n : null;
}

export function routeZoneCode(route: number): string {
  if (!Number.isInteger(route) || route < MIN_ROUTE || route > MAX_ROUTE) {
    throw new RangeError(`Número de ruta fuera de rango (${MIN_ROUTE}..${MAX_ROUTE}): ${route}`);
  }
  return `${ROUTE_ZONE_PREFIX}${String(route).padStart(3, '0')}`;
}

export function routeZoneName(route: number): string {
  return `Ruta ${route}`;
}

export function routeNumberFromZone(coZon: string | null | undefined): number | null {
  const m = /^CCS(\d{3})$/.exec((coZon ?? '').trim());
  if (!m) return null;
  const n = Number(m[1]);
  return n >= MIN_ROUTE ? n : null;
}
```

`lib/dwh/cutover.ts`:

```ts
// Profit Plus went live on 2026-03-28: 115 customers were loaded in one batch with the same
// saCliente.fecha_reg. Patrimonio / new customers are derived from that date, never stored.
// migrations/dwh/0040 repeats this literal; __tests__/unit/dwh/cutover.test.ts pins both.
export const MIGRATION_CUTOVER_DATE = '2026-03-28';

export type CustomerKind = 'patrimonio' | 'nuevo' | 'posterior';

const ISO = /^\d{4}-\d{2}-\d{2}$/;

function assertIso(d: string): void {
  if (!ISO.test(d)) throw new Error(`Fecha inválida '${d}'; se esperaba YYYY-MM-DD`);
}

export function isMigrationBatch(registeredDate: string): boolean {
  assertIso(registeredDate);
  return registeredDate === MIGRATION_CUTOVER_DATE;
}

// patrimonio in year Y: registered before Jan 1 of Y, or in the cutover batch.
// nuevo in year Y: registered in Y and not in the cutover batch.
export function customerKindInYear(registeredDate: string, year: number): CustomerKind {
  if (isMigrationBatch(registeredDate)) return 'patrimonio';
  const y = Number(registeredDate.slice(0, 4));
  if (y < year) return 'patrimonio';
  return y === year ? 'nuevo' : 'posterior';
}
```

```ts
import { sellerKey } from './codes';
import { routeZoneCode } from './route-zones';

// No seller x route table: a route's owner is derived from the sellers of its customers.
// The real world is 1 route -> 1 seller; anything else is reported, never silently accepted.

export interface OwnerInput { coCli: string; coVen: string; ruta: number | null }

export interface RouteOwner {
  route: number;
  zone: string;
  owner: string | null;                       // null on a tie or when no customer has a seller
  tie: boolean;
  customers: number;
  bySeller: { coVen: string; n: number }[];   // n desc, then code
}

export function deriveRouteOwners(rows: readonly OwnerInput[]): RouteOwner[] {
  const byRoute = new Map<number, OwnerInput[]>();
  for (const row of rows) {
    if (row.ruta == null) continue;
    const list = byRoute.get(row.ruta);
    if (list) list.push(row); else byRoute.set(row.ruta, [row]);
  }
  const out: RouteOwner[] = [];
  for (const [route, list] of [...byRoute].sort((a, b) => a[0] - b[0])) {
    const counts = new Map<string, { coVen: string; n: number }>();
    for (const row of list) {
      const code = row.coVen.trim();
      if (!code) continue;
      const key = sellerKey(code);
      const entry = counts.get(key);
      if (entry) entry.n++; else counts.set(key, { coVen: code, n: 1 });
    }
    const bySeller = [...counts.values()].sort((a, b) => b.n - a.n || a.coVen.localeCompare(b.coVen));
    const tie = bySeller.length > 1 && bySeller[1].n === bySeller[0].n;
    out.push({
      route, zone: routeZoneCode(route),
      owner: bySeller.length > 0 && !tie ? bySeller[0].coVen : null,
      tie, customers: list.length, bySeller,
    });
  }
  return out;
}

export type CoherenceKind = 'missing_route' | 'missing_seller' | 'route_without_owner' | 'seller_not_route_owner';

export interface CoherenceIssue {
  kind: CoherenceKind;
  coCli: string;
  ruta: number | null;
  coVen: string;
  owner: string | null;
  detail: string;
}

export function checkCoherence(rows: readonly OwnerInput[]): CoherenceIssue[] {
  const owners = new Map(deriveRouteOwners(rows).map(o => [o.route, o]));
  const issues: CoherenceIssue[] = [];
  for (const row of rows) {
    const coVen = row.coVen.trim();
    const base = { coCli: row.coCli, ruta: row.ruta, coVen };
    if (row.ruta == null) {
      issues.push({ ...base, kind: 'missing_route', owner: null, detail: 'sin ruta' });
    }
    if (!coVen) {
      issues.push({ ...base, kind: 'missing_seller', owner: null, detail: 'sin vendedor' });
    }
    if (row.ruta == null || !coVen) continue;
    const route = owners.get(row.ruta)!;
    if (route.owner == null) {
      issues.push({
        ...base, kind: 'route_without_owner', owner: null,
        detail: `ruta ${row.ruta} sin dueño (${route.bySeller.map(s => `${s.coVen}:${s.n}`).join(', ')}); deje un solo vendedor en la ruta`,
      });
    } else if (sellerKey(coVen) !== sellerKey(route.owner)) {
      issues.push({
        ...base, kind: 'seller_not_route_owner', owner: route.owner,
        detail: `vendedor ${coVen}, pero el dueño de la ruta ${row.ruta} es ${route.owner}`,
      });
    }
  }
  return issues;
}

// Gives every customer on a route with an owner that owner as seller. Owners are computed from
// the input as it is (so `owners.bySeller` shows the distribution BEFORE the override).
export function applyRouteOwners<T extends OwnerInput>(rows: readonly T[]): {
  rows: T[];
  owners: RouteOwner[];
  overrides: { coCli: string; ruta: number; from: string; to: string }[];
} {
  const owners = deriveRouteOwners(rows);
  const ownerOf = new Map(owners.map(o => [o.route, o.owner]));
  const overrides: { coCli: string; ruta: number; from: string; to: string }[] = [];
  const out = rows.map(row => {
    const owner = row.ruta == null ? null : (ownerOf.get(row.ruta) ?? null);
    if (!owner) return row;
    const current = row.coVen.trim();
    if (current && sellerKey(current) === sellerKey(owner)) return row;
    overrides.push({ coCli: row.coCli, ruta: row.ruta!, from: current, to: owner });
    return { ...row, coVen: owner };
  });
  return { rows: out, owners, overrides };
}
```

1. Customers come from the master workbook (`Maestro Clientes`; seller from the latest `Factura` line, unchanged). 2. Tracking rows whose code is not in the master get `route_code_not_in_master` (hint when exactly one master code has the same `looseCustomerKey`); never matched silently.

```ts
import type { Conflict, MappingRow } from './types';
import { looseCustomerKey, trimCode } from './codes';
import { DEFAULT_VISIT_FREQUENCY, parseVisitFrequency, type VisitFrequency } from './frequency';
import { applyRouteOwners, type RouteOwner } from './route-owners';
import { parseRouteNumber } from './route-zones';

export interface MasterRow { codigo: string; cliente: string; grupo: string }
export interface TrackingRow { codigo: string; ruta: unknown; frecuencia: unknown; fila: number }
export interface InvoiceLine {
  numero: string; renglon: number; fecha: string; coCli: string; coVen: string; tipoDocumento: string;
}

// ... iso(), parseSaleDate(), isLater() unchanged ...

export function buildMapping(
  master: MasterRow[],
  lines: InvoiceLine[],
  tracking: TrackingRow[],
  opts: { effectiveFrom: string },
): { rows: MappingRow[]; conflicts: Conflict[]; owners: RouteOwner[] } {
  const latest = new Map<string, InvoiceLine>();
  const sellers = new Map<string, Set<string>>();
  for (const line of lines) {
    // Only invoices that name a seller can decide the mapping; blank-seller lines are ignored.
    const coVen = trimCode(line.coVen);
    if (line.tipoDocumento !== 'Factura' || !coVen) continue;
    const normalized = { ...line, coVen };
    const best = latest.get(line.coCli);
    if (!best || isLater(normalized, best)) latest.set(line.coCli, normalized);
    if (!sellers.has(line.coCli)) sellers.set(line.coCli, new Set());
    sellers.get(line.coCli)!.add(coVen);
  }

  const conflicts: Conflict[] = [];

  // 1. Master customers (first row per code wins).
  const masterRows: MasterRow[] = [];
  const seen = new Map<string, string>();
  for (const r of master) {
    const coCli = trimCode(r.codigo);
    const nombre = trimCode(r.cliente);
    if (!coCli) { conflicts.push({ coCli: '', nombre, kind: 'missing_code', detail: 'fila sin código en Maestro Clientes' }); continue; }
    if (seen.has(coCli)) {
      conflicts.push({ coCli, nombre, kind: 'duplicate_code', detail: `ya existe como '${seen.get(coCli)}'; se conserva la primera fila` });
      continue;
    }
    seen.set(coCli, nombre);
    masterRows.push({ codigo: coCli, cliente: nombre, grupo: trimCode(r.grupo) });
  }

  // 2. Tracking workbook: exact (trimmed) code match only. A loose match is a hint, never a match.
  interface Route { ruta: number | null; frecuencia: VisitFrequency; fila: number }
  const routeOf = new Map<string, Route>();
  const masterLoose = [...seen].map(([coCli, nombre]) => ({ coCli, nombre, key: looseCustomerKey(coCli) }));
  for (const tr of tracking) {
    const coCli = trimCode(tr.codigo);
    if (!coCli) continue;
    if (!seen.has(coCli)) {
      const near = masterLoose.filter(x => x.key.length >= 5 && x.key === looseCustomerKey(coCli));
      const hint = near.length === 1 ? `; código parecido en el maestro: ${near[0].coCli} (${near[0].nombre})` : '';
      conflicts.push({ coCli, nombre: '', kind: 'route_code_not_in_master', detail: `fila ${tr.fila} del libro de seguimiento sin fila en Maestro Clientes${hint}` });
      continue;
    }
    const nombre = seen.get(coCli)!;
    const rawRoute = typeof tr.ruta === 'string' ? tr.ruta.trim() : tr.ruta;
    let ruta: number | null = null;
    if (rawRoute != null && rawRoute !== '') {
      ruta = parseRouteNumber(rawRoute);
      if (ruta == null) conflicts.push({ coCli, nombre, kind: 'invalid_route', detail: `fila ${tr.fila}: ruta '${String(rawRoute)}' no es un número 1..999` });
    }
    const rawFrec = tr.frecuencia == null ? '' : String(tr.frecuencia).trim();
    let frecuencia: VisitFrequency = DEFAULT_VISIT_FREQUENCY;
    if (rawFrec) {
      const parsed = parseVisitFrequency(rawFrec);
      if (parsed) frecuencia = parsed;
      else conflicts.push({ coCli, nombre, kind: 'invalid_frequency', detail: `fila ${tr.fila}: frecuencia '${rawFrec}' no válida; se usa ${DEFAULT_VISIT_FREQUENCY}` });
    }
    const prev = routeOf.get(coCli);
    if (prev) {
      if (prev.ruta !== ruta || prev.frecuencia !== frecuencia) {
        conflicts.push({ coCli, nombre, kind: 'duplicate_tracking_row', detail: `filas ${prev.fila} y ${tr.fila} difieren; ruta en blanco hasta resolver a mano` });
        prev.ruta = null;
      }
      continue;
    }
    routeOf.set(coCli, { ruta, frecuencia, fila: tr.fila });
  }

  // 3. One row per master customer present in the tracking workbook.
  const draft: MappingRow[] = [];
  for (const r of masterRows) {
    const tr = routeOf.get(r.codigo);
    if (!tr) {
      conflicts.push({ coCli: r.codigo, nombre: r.cliente, kind: 'not_in_tracking', detail: 'sin fila en el libro de seguimiento por ruta; no se incluye en el CSV' });
      continue;
    }
    if (tr.ruta == null) {
      conflicts.push({ coCli: r.codigo, nombre: r.cliente, kind: 'missing_route', detail: `fila ${tr.fila}: sin ruta válida; resolver a mano en el CSV (mapping:apply no corre sin ruta)` });
    }
    const last = latest.get(r.codigo);
    let coVen = '';
    let sourceNote = 'sin facturas en el libro';
    if (last) {
      coVen = last.coVen;
      sourceNote = `última factura ${last.numero} ${last.fecha}`;
      const all = sellers.get(r.codigo)!;
      if (all.size > 1) {
        conflicts.push({ coCli: r.codigo, nombre: r.cliente, kind: 'multi_seller', detail: `vendedores ${[...all].sort().join(',')} → se usa ${coVen} (${last.numero} ${last.fecha})` });
      }
    } else {
      conflicts.push({ coCli: r.codigo, nombre: r.cliente, kind: 'no_invoices', detail: 'sin facturas; el vendedor sale del dueño de su ruta' });
    }
    draft.push({
      coCli: r.codigo, nombre: r.cliente, coVen, grupo: r.grupo, ruta: tr.ruta, frecuencia: tr.frecuencia,
      effectiveFrom: opts.effectiveFrom, sourceNote,
    });
  }

  // 4. Route owners: the seller with most customers on a route owns it; everyone on it gets that seller.
  const { rows: owned, owners, overrides } = applyRouteOwners(draft);
  const overrideOf = new Map(overrides.map(o => [o.coCli, o]));
  const rows = owned.map(r => {
    const o = overrideOf.get(r.coCli);
    return o ? { ...r, sourceNote: `${r.sourceNote}; vendedor de la ruta ${o.ruta}: ${o.to}` } : r;
  });
  const nameOf = new Map(draft.map(r => [r.coCli, r.nombre]));
  for (const o of overrides) {
    if (!o.from) continue;
    conflicts.push({ coCli: o.coCli, nombre: nameOf.get(o.coCli) ?? '', kind: 'seller_overridden_by_route_owner', detail: `ruta ${o.ruta}: ${o.from} → ${o.to} (dueño de la ruta)` });
  }
  for (const o of owners) {
    const dist = o.bySeller.map(s => `${s.coVen}:${s.n}`).join(', ');
    if (o.tie) {
      conflicts.push({ coCli: '', nombre: `Ruta ${o.route}`, kind: 'route_owner_tie', detail: `empate entre ${dist}; deje un solo vendedor para todos los clientes de la ruta en el CSV` });
    } else if (o.owner == null) {
      conflicts.push({ coCli: '', nombre: `Ruta ${o.route}`, kind: 'route_without_owner', detail: 'ningún cliente de la ruta tiene vendedor; asigne uno en el CSV' });
    }
  }

  // Factura customers that the master sheet never lists would silently keep their ERP seller/group.
  // Suggestion only: same code ignoring punctuation/case, or one is the other plus a suffix.
  const looselyMatches = (k: string) => masterLoose.filter(x =>
    x.key.length >= 5 && k.length >= 5 && (k === x.key || k.startsWith(x.key) || x.key.startsWith(k)));
  const reported = new Set<string>();
  for (const line of lines) {
    const code = trimCode(line.coCli);
    if (line.tipoDocumento !== 'Factura' || !code || seen.has(code) || reported.has(code)) continue;
    reported.add(code);
    const near = looselyMatches(looseCustomerKey(code));
    const hint = near.length === 1 ? `; código parecido en el maestro: ${near[0].coCli} (${near[0].nombre})` : '';
    conflicts.push({ coCli: code, nombre: '', kind: 'sales_code_not_in_master', detail: `código de la hoja de ventas sin fila en Maestro Clientes${hint}` });
  }
  rows.sort((a, b) => a.coCli.localeCompare(b.coCli));
  return { rows, conflicts, owners };
}
```

```sql
-- migrations/mssql/0018_pApi_routes.sql
-- Procs used by `bun run mapping:apply` for customer routes and visit frequency.
-- A route is a saZona row coded CCSnnn (nnn = route number from the tracking workbook). The code
-- is char(6) because saZona.co_zon / saCliente.co_zon are; legacy zones (CCS, 001.., CCS-11) are
-- never touched. Visit frequency lives in saCliente.frecu_vist (varchar(60), free in the ERP) and is
-- constrained here to SEMANAL / QUINCENAL / MENSUAL (extend with a new CREATE OR ALTER).
-- saCliente.tip_cli, co_seg and co_ven are NOT written by these procs.

CREATE OR ALTER PROCEDURE [pApiInsertarZona]
    ( @sCoZon CHAR(6), @sZonDes VARCHAR(60), @sCoUsIn CHAR(6) )
AS
BEGIN
    SET NOCOUNT ON;
    BEGIN TRY
        DECLARE @sTrim VARCHAR(6) = RTRIM(@sCoZon);
        -- Case-sensitive on purpose: the database collation is case-insensitive.
        IF @sTrim COLLATE Latin1_General_BIN NOT LIKE 'CCS[0-9][0-9][0-9]'
            RAISERROR('Codigo de ruta %s invalido (se espera CCSnnn)', 16, 1, @sTrim);
        -- Idempotent: an existing zone is left exactly as it is.
        IF EXISTS (SELECT 1 FROM saZona WHERE co_zon = @sCoZon) RETURN;
        INSERT INTO saZona (co_zon, zon_des, co_us_in, fe_us_in, co_us_mo, fe_us_mo, rowguid)
        VALUES (@sCoZon, @sZonDes, @sCoUsIn, GETDATE(), @sCoUsIn, GETDATE(), NEWID());
    END TRY
    BEGIN CATCH
        DECLARE @ErrorMessage NVARCHAR(4000) = ERROR_MESSAGE();
        DECLARE @ErrorNumber INT = ERROR_NUMBER();
        RAISERROR(@ErrorMessage, 16, @ErrorNumber);
    END CATCH
END
GO

CREATE OR ALTER PROCEDURE [pApiActualizarRutaCliente]
    ( @sCoCli CHAR(16), @sCoZon CHAR(6), @sFrecuVist VARCHAR(60), @sCoUsMo CHAR(6) )
AS
BEGIN
    SET NOCOUNT ON;
    BEGIN TRY
        BEGIN TRAN;
        DECLARE @sCoCliTrim VARCHAR(16) = RTRIM(@sCoCli);
        DECLARE @sCoZonTrim VARCHAR(6)  = RTRIM(@sCoZon);
        DECLARE @sFrec VARCHAR(60) = UPPER(LTRIM(RTRIM(@sFrecuVist)));

        IF NOT EXISTS (SELECT 1 FROM saCliente WHERE co_cli = @sCoCli)
            RAISERROR('Cliente %s no encontrado', 16, 1, @sCoCliTrim);
        IF NOT EXISTS (SELECT 1 FROM saZona WHERE co_zon = @sCoZon)
            RAISERROR('Zona %s no encontrada', 16, 1, @sCoZonTrim);
        IF @sFrec IS NULL OR @sFrec NOT IN ('SEMANAL', 'QUINCENAL', 'MENSUAL')
            RAISERROR('Frecuencia %s invalida (SEMANAL, QUINCENAL o MENSUAL)', 16, 1, @sFrec);

        UPDATE saCliente
        SET co_zon = @sCoZon, frecu_vist = @sFrec, co_us_mo = @sCoUsMo, fe_us_mo = GETDATE()
        WHERE co_cli = @sCoCli;

        COMMIT TRAN;
    END TRY
    BEGIN CATCH
        IF @@TRANCOUNT > 0 ROLLBACK TRAN;
        DECLARE @ErrorMessage NVARCHAR(4000) = ERROR_MESSAGE();
        DECLARE @ErrorNumber INT = ERROR_NUMBER();
        RAISERROR(@ErrorMessage, 16, @ErrorNumber);
    END CATCH
END
GO

-- Rollback only (same pattern as pApiRestaurarVendedorCliente in 0017): the previous frecu_vist may be
-- NULL or free text, which pApiActualizarRutaCliente refuses.
CREATE OR ALTER PROCEDURE [pApiRestaurarRutaCliente]
    ( @sCoCli CHAR(16), @sCoZon CHAR(6), @sFrecuVist VARCHAR(60) = NULL, @sCoUsMo CHAR(6) )
AS
BEGIN
    SET NOCOUNT ON;
    BEGIN TRY
        BEGIN TRAN;
        DECLARE @sCoCliTrim VARCHAR(16) = RTRIM(@sCoCli);
        DECLARE @sCoZonTrim VARCHAR(6)  = RTRIM(@sCoZon);

        IF NOT EXISTS (SELECT 1 FROM saCliente WHERE co_cli = @sCoCli)
            RAISERROR('Cliente %s no encontrado', 16, 1, @sCoCliTrim);
        IF NOT EXISTS (SELECT 1 FROM saZona WHERE co_zon = @sCoZon)
            RAISERROR('Zona %s no encontrada', 16, 1, @sCoZonTrim);

        UPDATE saCliente
        SET co_zon = @sCoZon, frecu_vist = @sFrecuVist, co_us_mo = @sCoUsMo, fe_us_mo = GETDATE()
        WHERE co_cli = @sCoCli;

        COMMIT TRAN;
    END TRY
    BEGIN CATCH
        IF @@TRANCOUNT > 0 ROLLBACK TRAN;
        DECLARE @ErrorMessage NVARCHAR(4000) = ERROR_MESSAGE();
        DECLARE @ErrorNumber INT = ERROR_NUMBER();
        RAISERROR(@ErrorMessage, 16, @ErrorNumber);
    END CATCH
END
GO
```

```ts
function snapshotOf(plan: Plan): RunSnapshot {
  const customers = new Map<string, RunSnapshot['customers'][number]>();
  const entry = (coCli: string) => {
    if (!customers.has(coCli)) customers.set(coCli, { coCli });
    return customers.get(coCli)!;
  };
  for (const c of plan.customerSeller) entry(c.coCli).coVen = c.from;
  for (const c of plan.customerSegment) if (c.from) entry(c.coCli).coSeg = c.from;
  for (const c of plan.customerRoute) entry(c.coCli).route = { coZon: c.fromZon, frecuVist: c.fromFrec };
  return {
    customers: [...customers.values()],
    docs: plan.docSeller.map(d => ({ kind: d.kind, docNum: d.docNum, coVen: d.from })),

}
```

```sql
CREATE OR ALTER PROCEDURE dwh.Load_Dim_Zone
AS
BEGIN
    SET NOCOUNT ON;
    SET XACT_ABORT ON;
    BEGIN TRAN;
    DELETE FROM dim.Dim_Zone;
    INSERT INTO dim.Dim_Zone (ZoneCode, ZoneName, IsRoute, RouteNumber)
    SELECT src.co_zon, RTRIM(src.zon_des), CASE WHEN rn.n IS NULL THEN 0 ELSE 1 END, rn.n
    FROM Ncake_a.dbo.saZona src
    OUTER APPLY (
        SELECT CASE WHEN RTRIM(src.co_zon) COLLATE Latin1_General_BIN LIKE 'CCS[0-9][0-9][0-9]'
                     AND SUBSTRING(RTRIM(src.co_zon), 4, 3) <> '000'
                    THEN CAST(SUBSTRING(RTRIM(src.co_zon), 4, 3) AS int) END AS n

    COMMIT TRAN;
END

AS
BEGIN
    SET NOCOUNT ON;
    DECLARE @Watermark binary(8) = (SELECT LastValidador FROM dwh.EtlWatermark WHERE SourceTableName = 'saCliente');
    DECLARE @NewWatermark binary(8);
    DECLARE @Now datetime2(3) = SYSUTCDATETIME();
    DECLARE @RowCount int;
    DECLARE @CutoverDate date = '2026-03-28';

    -- intentionally NOT part of this diff (in-place syncs below, see 0030/0031); RegisteredDate,
    -- IsMigrationBatch and VisitFrequency are. VisitIntervalDays is computed from VisitFrequency.

    SET tgt.ValidTo = @Now, tgt.IsCurrent = 0
    FROM dim.Dim_Customer tgt
    INNER JOIN Ncake_a.dbo.saCliente src ON RTRIM(src.co_cli) COLLATE SQL_Latin1_General_CP1_CI_AS = RTRIM(tgt.CustomerCode)
    OUTER APPLY (

                    THEN UPPER(RTRIM(src.frecu_vist)) END AS Freq

         OR ISNULL(RTRIM(tgt.DefaultSalesRepCode), '') <> ISNULL(RTRIM(src.co_ven), '') COLLATE SQL_Latin1_General_CP1_CI_AS
         OR ISNULL(tgt.IsLegalEntity, 0) <> ISNULL(src.juridico, 0)
```

```ts
export interface DimRouteRow { coCli: string; zone: string | null; frequency: string | null; rep: string | null }
export interface RouteMismatch {
  coCli: string;
  field: 'ZoneCode' | 'VisitFrequency' | 'DefaultSalesRepCode';
  expected: string;
  actual: string | null;
}

export function compareRouteDim(rows: MappingRow[], dim: DimRouteRow[]): RouteMismatch[] {
  const byCode = new Map(dim.map(d => [d.coCli.trim().toUpperCase(), d]));
  const out: RouteMismatch[] = [];
  for (const r of rows) {
    const d = byCode.get(r.coCli.trim().toUpperCase());
    if (!d) continue;
    if (r.ruta != null) {
      const want = routeZoneCode(r.ruta);
      if ((d.zone ?? '').trim() !== want) out.push({ coCli: r.coCli, field: 'ZoneCode', expected: want, actual: d.zone?.trim() ?? null });
      if (d.frequency !== r.frecuencia) out.push({ coCli: r.coCli, field: 'VisitFrequency', expected: r.frecuencia, actual: d.frequency });
    }
    if (r.coVen.trim() && (d.rep == null || sellerKey(d.rep) !== sellerKey(r.coVen))) {
      out.push({ coCli: r.coCli, field: 'DefaultSalesRepCode', expected: r.coVen.trim(), actual: d.rep?.trim() ?? null });
    }
  }
  return out;
}

export async function findRouteMismatches(pool: sql.ConnectionPool, rows: MappingRow[]): Promise<RouteMismatch[]> {
  const res = await pool.request().query(`
    SELECT RTRIM(CustomerCode) AS coCli, RTRIM(ZoneCode) AS zone, VisitFrequency AS frequency,
           RTRIM(DefaultSalesRepCode) AS rep
    FROM dim.Dim_Customer WHERE IsCurrent = 1`);
  return compareRouteDim(rows, res.recordset as DimRouteRow[]);
}
```
